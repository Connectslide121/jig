# Phase 13 — "What Jig can do" (an in-app about page)

**Goal:** one place in Jig that shows what it can do — each part with a screenshot, the extension
slots and what you can build with them, your add-ons and skills, what Claude can configure — in a
way you can act on right away (D-078).

**Done when:** the page opens from the top bar, the Tools menu, the welcome screen and Settings →
About, lists every slot with the add-ons that use it, and its examples start a build or a chat.

## Checklist

- [x] Core tab `jig.about` ("What Jig can do"), singleton, with a resizable section list and scroll-spy
- [x] Overview with live numbers (projects, repos, add-ons on, slots, tools for Claude) and buttons
- [x] Sections with screenshots (click to enlarge): chats, workspaces, Git, configure, build, themes,
      suggestions, plan usage
- [x] Extension slots: live grid from `@jig/sdk` `SLOTS`, which add-ons use each, an `addon.json`
      snippet, "Build something here"
- [x] Your add-ons with the slots each uses
- [x] Claude configures Jig: example prompts with "Try in a chat" (new chat, text in the composer, not
      sent), the tool list, the protected settings
- [x] Skills: `about.skills` reads SKILL.md front matter from `~/.claude/skills` and the active
      project's `.claude/skills`
- [x] Build examples per level open the Build dialog with the goal filled in
- [x] Keyboard shortcuts, live from the registered actions (click runs one)
- [x] Entry points: top bar `?`, Tools → What Jig can do, welcome screen, Settings → About
- [x] Screenshots regenerated by `e2e/screenshots.spec.ts` (`JIG_SCREENSHOTS=1`)
- [x] Tests: skills unit test, e2e (slots, Git add-on on `view`, project skill, Try in a chat)

## Notes

- The screenshots are made with the fake engine and a demo workspace; regenerate them when the UI
  changes noticeably (see `docs/reference/about.md`).
