# Teasers: Jig, Factory, Motion

Three free compositions (D-474), rendered by Motion's renderer (HyperFrames + FFmpeg) at 1080p, 30 fps,
no voice. Each `*.composition.json` is what a chat would pass to `addon_motion_compose`, with
screenshots from the "What Jig can do" page and the Factory and Motion showcases as `media/`.

| Video | Length | Look |
|---|---|---|
| [jig.mp4](jig.mp4) | 25 s | Amber kinetic type, a tilted chat, a 3D wall of Jig's views |
| [factory.mp4](factory.mp4) | 25 s | Lime on slate, a stage conveyor from tender to release, design directions, the demo |
| [motion.mp4](motion.mp4) | 25 s | Coral and violet, an editor timeline with a playhead, the chat card, bouncing type |
