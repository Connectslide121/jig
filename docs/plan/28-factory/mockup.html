Factory — how it looks

A static mockup for phase 28 (docs/plan/28-factory.md; screens specified in ui.md). Jig Dark colours, sample data only, no scripts. Product names are placeholders. The build follows Jig's UI rules: tokens, aligned columns, status at the right edge, whole cards clickable, modals for forms, no layout shift.

1 · The Floor: every run of the project

Opened from the top bar's factory button (its count is what waits for you). The sidebar is the compact "Factory" view (View → Views). Cards are fixed height; the ring, time and "you" slots are always there.

Each card has a suggested answer: ✓ accepts it, ✎ edits, 🎤 dictates. A new round replaces the cards in place; earlier rounds fold into one line. The brief on the right is a fixed grid: sections being written show skeleton lines, gaps are marked.
