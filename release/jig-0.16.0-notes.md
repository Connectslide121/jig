## New

- **Pages.** Claude can publish HTML pages (reports, overviews, mockups) into Jig's new Pages view. A card in the chat opens the page; pages keep their versions and can be saved as a file.
- **What's new in the app.** A What's new tab (Jig menu, Settings → About, What Jig can do and the Updates card in Get started) shows every version's release notes, newest first, with a link to all releases on GitHub.
- **Pin tabs.** Pin a tab in the main area to keep it first and stop it from being closed by accident; pins are saved with the layout.
- **Run meeting actions.** In Review meeting actions, run an action right away in a new chat in its project, mark it done or dismiss it. Handled actions move to their own tab, where you can restore them.
- **Stop lines in the task queue.** Put a Stop here line between tasks: Start runs the tasks above it, and the next Start runs the next block. Lines can be dragged, and tasks dragged across them.
- **Reorganize the queue.** A Reorganize button lets a small AI regroup and reorder the tasks that haven't run yet.
- **Park a whole chat group** of tasks at once; it stays together in the pool.
- **ChatGPT completes code too.** The editor's inline completion can now run on ChatGPT (Codex) as well as Claude; pick it in Settings with its own model.

## Improved

- **Meetings window.** Calendar, Chats and Meetings now live in one window with tabs, and the top-bar button opens it directly. Meeting history moved there from the main window.
- **Meeting history** shows the notes at full width; the Transcript button shows the transcript beside them in a split you can resize.
- **Task queue model.** Runs on in the queue header now picks a model too; a task's own choice still wins. Tasks handed over to the other provider after a limit show both providers' marks.
- **Tasks carry on after a restart.** A task whose turn was cut off by closing or updating Jig is told to carry on, and running queues pause while Jig installs an update and resume after the restart.
- **Faster ChatGPT caption translation** in meetings.
- **Phone channels.** Switching between Telegram and Teams keeps the other channel's setup, so switching back needs no new setup.
- **Claude's browser** only comes to the front when a chat opens a new page, instead of on every action.
- Speech device lists name the system default device, for example "System default (Headset)".
- Empty views show their buttons in a centred row with calmer spacing.
- Claude's mark is as big as ChatGPT's everywhere; usage bars in the footer stay green while there is room.

## Fixed

- Jig no longer mentions Artifacts, which Claude Code doesn't offer to Jig chats; Pages replaces them.
- The Hey Jig status item's icon and label are centred again.
