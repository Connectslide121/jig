## New

- **Teams calls:** call people in your organisation from the Meetings window, and answer calls that ring in Jig while it runs. Calls are kept like meetings, with Call back.
- **Live captions in your language:** pick a language in the live transcript; each line shows the translation with what was said under it (Teams translates; needs Teams Premium for the meeting).
- **Code completion:** suggestions as you type in the editor, Tab to take them, from GitHub Copilot (optional, set up from Get started) or Claude (Settings → Editor).
- **Language servers:** with a language server installed (TypeScript, Python, C#, Go, Rust, JSON, CSS, HTML), the editor shows errors as you type, hover information, go to definition (F12), references, rename (F2) and formatting. Settings → Editor lists them with Install.
- **Project knowledge:** documents on each project's Home (text, PDF, Word, Excel, PowerPoint) that every chat in the project can read.
- **Import from claude.ai:** turn your claude.ai projects (instructions and knowledge) into Jig projects from claude.ai's data export.
- **Task queue per project**, with a history of every run and an editable review of the tasks Claude proposes.
- **Meeting history** in the main window, and `@` mentions of meetings in chats.
- **Azure DevOps boards** per project, with their real columns and cards.
- **Add-ons:** restore an edited add-on to its original, and share an edited one as a separate copy.

## Improved

- Mentioned files are highlighted in the message box, with a chip each that opens the file.
- The latest steps line in a chat shows it is still working between steps.
- The context window card stays open on hover and has Compact now.
- Git's sync button says what it does (Pull, Push, Sync, Publish).
- Home has a New chat button; scripts can be restarted; installing an update says what happens next.
