## New

- **Chats on ChatGPT.** Next to the model picker in a new chat, pick Claude or ChatGPT (sign in to the Codex CLI from Get started first). ChatGPT chats get Jig's tools, your project's approved MCP servers, your Claude Code skills, Plan only with the plan card, questions on the question card, and a suggested next message after each turn.
- **Choose the provider per project** in the project's settings, and the default for new chats in **Settings → Chats** (formerly Claude Code), now grouped into Claude chats, ChatGPT chats and All chats.
- **Open a saved chat** lists Claude Code conversations and Codex threads together and opens either.
- **Claude's browser gives each chat its own page**, shown as tabs in the browser view, so two chats can browse at once without getting in each other's way. Logins are shared by default; separate logins are a setting.
- **Local meeting transcript:** when Teams captions aren't available, Jig transcribes the call on your computer (audio is never stored or sent). Turn it off in the transcript's ⋯ menu.
- **Noise suppression on your microphone in calls**, on by default, switchable from the call's menu and Devices….
- **Reorder the task queue by drag and drop**, and Claude can now move queued tasks and choose which chat they continue.
- **Edit queued messages** in the chat's own message box.
- **Sign in to Azure tenants with a code**, or in the browser, instead of Windows' account window.

## Improved

- Meeting devices follow Windows' default (the selects name which device that is), your picks are remembered, and a new default or a headset plugged in during a call is picked up.
- Plan, question and permission cards name the chat's provider.
- The task queue waits for a chat's background work before moving on, asks once for a missing report, and accepts reports that arrive late.
- The usage footer is calmer: reset times are in the hover card, and meters only turn amber or red near a limit.
- Task queue columns and menu badges stay on one line.

## Fixed

- Captions work in group meetings again.
- Claude's browser no longer hangs a chat: slow loads, stuck pages, dialogs and crashes now end with a message Claude can act on.
- The screen-share dialog says sound isn't shared, instead of showing a switch that did nothing.
