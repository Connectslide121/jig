Jig’s first published Windows release brings Claude Code chats and day-to-day development tools into one workbench.

### Highlights

- Project-based Claude Code chats with files, image pasting, tool results and configurable models.
- Git, repositories, pipelines, scripts and terminals alongside your chats.
- A native browser for your own browsing, plus a separate Claude-controlled browser for checking web UI and helping with sign-ins.
- Image previews and Git image comparisons with zoom buttons, 10–800% presets, Fit/100% and Ctrl/Cmd + scroll.
- Editable file previews, project notes, workflows, a task queue and a curated skills library.
- Local activity-based suggestions with a readable layout and more careful handling of screenshot and browser-verification evidence.
- A repository-owned release skill usable by Codex, Claude Code and Jig’s own repository chats.

### Installation and updates

Download **Jig-Setup-0.1.1.exe** for Windows x64. Close Jig and run the installer to update an existing installation. Chats and settings live separately in your Jig home.

The installer is unsigned, so Windows may display a SmartScreen warning. Installed Jig’s **Check for updates** opens the latest release page; installation is manual.

### Known limitations

Speech and Teams meeting features require their documented device/service setup and remain early features. Real-device and real-call acceptance testing is still outstanding. No silent auto-update or code-signing is included in this release.
